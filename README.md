## 🚀 How to Run the Project

Follow these steps to run StockGuard locally.

### 1. Navigate to the frontend directory

```bash
cd frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Access the application

Open your browser and visit the `localhost` URL displayed in your terminal.
